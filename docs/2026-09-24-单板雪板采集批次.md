## 选品热度与边界

国内电商评价/评论数作为可见关注度代理，不是销量、成交件数或市场份额；数字为 2026-09-24 检索到的页面快照，平台聚合变体时可能把不同尺码/配色评论合并。京东可见迪卡侬 SNB 100 约 95+、All Road 900 约 32+、Park & Ride 500 约 51+ 评论；Burton Talent Scout 在热雪社区有 14 个评价，Salomon Huck Knife 5 个、Assassin Pro / Assassin 各 4 个。BC Stream R2 / Riders' Spec DR / RX 在热雪社区分别有 8 / 7 / 4 个评价；OGASAKA FC / SHIN / CT 分别有 5 / 3 / 1 个评价；GRAY DESPERADO Type-R 与基础款页面分别有 3 / 2 个评价。CAPiTA DOA / Super DOA / Kazu、Nitro Team / Beast 的热雪社区页面可见评价数分别为 14 / 6 / 4 与 9 / 5。来源主要是[京东迪卡侬雪板商品列表](https://www.jd.com/pinpai1/1318c561e8dc56000caa.html)、[京东单板价格/评论列表](https://www.jd.com/jiage/13189173663aee4d657b.html?catID=17346&electedExtAttrSet=&extAttrValue=expand_name%2C&sort_type=sort_default)、[热雪单板评论排序页](https://thesnowfever.com/list/snowboards?b_id=1&level=&sort=-comment_count&style=common)、[GRAY 品牌筛选页](https://thesnowfever.com/list/snowboards?brand=72)及[Burton Talent Scout 详情](https://thesnowfever.com/detail/burton-talent-scout-snowboard-4579)。

热雪社区并非电商平台，所以它的评价数仅作补充热度信号；目前无法从可访问的国内电商结果中可靠确认 K2 Passport / Excavator / Alchemist、Jones 两款女板以及部分日本刻滑板的同口径商品评论数。它们保留在本批是为了完成用户点名品牌覆盖，不能据此宣称已验证为各品牌国内销量前列。后续若要严格执行“按电商热度排名”，应优先补齐这些型号的京东/天猫具名 SKU 评论快照，再决定是否替换。

## 采集与入库规则

- 可自动解析的目标写入 `scripts/collector/examples/foreign-hot-snowboard-phase1-targets.json`。当前采集器已有 Burton、Jones、Nitro 等部分品牌适配器；BC Stream、GRAY、OGASAKA、Decathlon、Salomon、K2 目前走通用快照适配器，通用适配器不会自动产生完整规格草稿，因此这些型号只按可追溯的官方 / 零售商品资料人工录入并保留 URL，不虚报为机器自动抽取。
- 2026-09-24 采集器实跑：23 个目标使用 23 个不同 URL，22 次请求成功、4 份规格草稿、0 个身份/季节质量失败；Decathlon All Road 900 页面返回 HTTP 403，保留失败快照。采集器未启用自动通过，正式 seed 保持人工核对的资料，不以草稿自动覆盖。
- 商品价格只在可核实的中国人民币来源明确对应到具体型号与年份时录入；本批新商品均未补价格，未把日元、欧元、英镑或美元换算成人民币。
- 不采集/复制未确认授权的商品图片；新 seed 的图片保持空。
- 原始快照和 `run-summary.json` 保存在本地临时审计目录 `data/tmp/collector-foreign-hot-snowboard-phase1-rerun/`。
- 本地全量校验通过：类目 127 / 品牌 48 / 产品 145。线上单品导入器新增 23 款；雪板公开列表总数由 40 增至 63。23/23 个公开详情均核对通过，品牌、型号、年份和单板类目匹配；`/api/health` 显示 API、数据库和 Redis 正常。只同步数据库，未重导全库、重启服务或部署网站。
