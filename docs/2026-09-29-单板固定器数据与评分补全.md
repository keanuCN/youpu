## 评分口径

这些分数是档案编辑基于已记录的产品定位、结构、穿脱系统、官方硬度和适用场景作出的 0–10 分比较，不是本站用户实测均分，也不代表品牌官方总评分。尤其 COSONE Step On 的公开参数仍不完整，其除穿脱便利外的分数仅作占位级编辑判断，后续拿到可核实规格后应复评。

目前这 60 款都没有可比的人民币成交价数据，所以性价比暂统一记为中性 5 分，不能据此得出真实价格竞争力结论；收集到可靠的国内价格与相同条件报价后再逐款调整。

硬度只录入可核对的官方数值，不将不同品牌的 soft/medium/stiff 等描述擅自换算成统一数字。Union 四款硬度依据各自官方商品页；例如 [Atlas Pro 官方页](https://unionbindingcompany.com/products/union-atlas-pro-unisex-snowboard-binding-2027)、[Legacy 官方页](https://unionbindingcompany.com/fr-ca/products/union-legacy-womens-snowboard-binding-2027)、[Trilogy 官方页](https://unionbindingcompany.com/products/union-trilogy-womens-snowboard-binding-2027) 与 [Ultra 官方页](https://unionbindingcompany.com/products/union-ultra-womens-snowboard-binding-2027)。

其他品牌规格仍以每款 YAML 中 `data_source.origin_url` 记录的来源为准。种子档案已同步到本地数据库并经 API 核验；未同步线上数据库，也未部署。
