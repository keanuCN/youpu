## 更换域名对注册登录的影响

1. 账号、密码哈希、数据库中已有收藏和评论仍在原后端，不由域名生成；域名入口反向代理到同一 API，不需要重新注册。
2. 前端会话 access/refresh token 保存在浏览器 localStorage，按来源隔离。旧 IP、旧域名的登录状态不会自动带到新域名，需要在 HTTPS 正式域名重新登录；只保存在旧来源浏览器中的游客记录、投票和部分历史也不会自动迁移。
3. CORS、新域名发件人和邮件 DNS 已有配置。验证码邮件使用数字代码，没有依赖旧域名的确认链接；实际投递仍必须用受控邮箱验证，配置存在不能替代收件验收。
4. 生产环境变量和浏览器脚本使用新域名/同源地址，当前未发现因为更换域名而把认证请求发回旧站的证据。
