## 采集与质量边界

- 种子只记录能由官方商品页或官方产品目录确认的型号、穿脱结构与明确兼容信息。官网未给出的规格留空，不按常识估值；Rome 仅录入官网明确的 Katana AW Pro FASE 硬度 9/10。
- 价格只采人民币且必须有精确国内 SKU 证据；本批不把外币价格换算成人民币。图片授权未确认，所有新增产品图片留空。
- 国内电商页面用于选品热度判断，不作为产品规格的权威来源；评价数是页面快照，不作销量陈述。
- COSONE 官网精选卡片能确认 Step On 名称与品牌主推信息，但详细兼容范围没有在可读页面中找到，因此兼容性留空。
- 新增品牌：COSONE、Flow、Rome；其余品牌复用已有品牌目录。

## 追加内容质量修复（2026-09-28）

- 核查全部 60 款后发现，原正式 seed 虽有型号与穿脱系统，但大量安装系统、硬度手感、适用场景及商品图字段为空；修复后 59 款有与型号对应的官方商品图、安装系统和适用场景。COSONE Step On 暂未找到可确认对应型号的官方商品图与完整规格，继续保留缺省。
- 固定器类目新增 `flexFeel`（柔软、中等、偏硬等）字段，避免把品牌的文字硬度误当成统一数字。当前 17 款有官方数字硬度，26 款有官方文字硬度；未能从官方资料核实的值仍留空。
- 图片记录保留品牌官方图片 URL 与来源说明；授权状态尚未单独核验。为本地预览登记了对应官方 CDN 路径，代理实测返回 200；迪卡侬图片固定使用代理支持的 WebP 协商格式。
- 目录快照导出会将 `data/snowboard-binding/` 正式档案叠加到公开目录快照，确保本地开发列表和详情可看到新图片及参数。当前本地固定器目录与公开 API 商品总数均为 60；仅更新本地 seed/快照，没有部署网站，也没有修改线上数据库。
