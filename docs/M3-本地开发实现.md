# M3 本地开发实现记录

更新时间：2026-09-20

## 本轮范围

本轮只做本地开发和联调，不做线上闭环、部署、批量文件导入和生产安全加固。

- 用户账号：邮箱验证码注册、邮箱密码登录、刷新令牌、退出、邮箱验证码重置密码、个人资料。
- 社区互动：产品评分、实测评论、回复、有帮助、收藏、通知。
- 社区治理：评论举报，后台查看和更新举报状态；后台查看、隐藏、拒绝评论。
- 后台审计：记录产品、品牌、类目和审核状态变更的操作人、动作及前后快照。
- 推荐问卷：保留现有问卷界面，提交后将推荐结果持久化到本地 API 的 `recommendation_run`。
- 埋点关联：登录态上报事件，后台数据分析可按活跃账号统计。
- 本地数据：单板 40 件，羽毛球拍 5 件、路亚竿 5 件、运动相机 10 件、公路车 8 件、山地车 6 件，数据库已完成幂等导入；运动相机、公路车和山地车首批只录入已核验的官方规格，价格按 USD 展示，未核实的价格和用户行为数据保持为空；路亚竿 5 件现已同步加入前端本地内容包，API 不可用时仍可浏览和打开详情。

## 本地入口

- Web：`http://localhost:3000`
- 后台：`http://localhost:3002/admin/`
- API：`http://localhost:3001/api`

当前本地后台令牌由启动进程注入；不要把实际令牌写入仓库文件。

## 邮箱真实投递配置

- 当前邮件发送实现使用 `Nodemailer + SMTP`，开发和生产环境都要求接入真实邮件服务；Resend 的 SMTP 主机为 `smtp.resend.com`，用户名为 `resend`，密码使用 API Key。
- 在 Resend 中验证 `xiaopang.club`，把平台要求的 SPF、DKIM 记录添加到腾讯云 DNS，再创建发件地址，例如 `no-reply@xiaopang.club`。
- 将 SMTP 配置写入 `apps/api/.env`，不要提交到 Git；未配置 SMTP 时开发和生产环境都会返回服务不可用，不生成、不返回本地验证码。

## 数据完整度规则

- 新增产品先录入可从官方产品页直接核验的规格；目前 2027 数据中的 16 条 CAPiTA 和 9 条 Jones 单板种子均已补充硬度、板型、结构、底材和适用场景。
- 产品内容质量首轮补齐：为上述 25 件 2027 单板补充官方海外公开价（保留 USD）、官方产品图来源、中文一句话点评和有谱编辑首版估分；编辑分数仍待实测校正，图片版权仍待核验。
- 价格、图片、编辑评分、中文编辑分析和实测数据需要区分来源：本地演示可使用已留痕的官方 / 公开零售参考资料，正式发布前仍需核实中国区价格、图片授权和实测依据；没有可信来源时保持为空，前台统一显示“待补充”，不以 0 值代替。
- 新增品类图片仅登记了明确的远程图片路径并接入本地代理；正式上线前应迁移到自有 COS，避免依赖外部站点和未确认授权。
- 运动相机首批覆盖 DJI Osmo Action 6 / 5 Pro / 4、GoPro HERO13 / 12 / 11、Insta360 Ace Pro 2 / Ace Pro / GO 3S / GO 3；规格来自品牌官方产品页或官方手册，编辑分数属于本地首版判断，仍待实测校正。
- 公路车首批覆盖 Canyon Endurace / Aeroad、Specialized Tarmac SL8、Giant Defy / TCR / Propel；规格和产品图来自品牌官方产品页，6 件保留已核实的 USD 参考价，Specialized 两件价格继续显示“待补充”。
- 山地车首批覆盖 Canyon Neuron / Spectral、Specialized Stumpjumper 15 / S-Works Epic 8、Giant XTC Advanced / Trance X Advanced；规格、价格和产品图来自品牌官方产品页，Spectral 的页面摘要与组件区材质描述存在差异，已在本地参数中明确标记待复核；公路车和山地车详情页已增加结构化尺码 / 几何表，缺失的官方几何仍明确标注待补齐。
- 后台产品页支持按缺图片、缺价格、缺来源、缺编辑评分筛选；总览会显示对应待补数量并可直接进入补齐队列。
- 本地 API 内容请求使用 `no-store`，重新 seed 或后台修改后，前台详情和列表会读取最新数据。

## 主要 API

| 能力 | 入口 |
| --- | --- |
| 邮箱验证码 | `POST /api/auth/email/code`，用途为 `register` 或 `reset-password` |
| 邮箱注册 / 登录 | `POST /api/auth/register`、`POST /api/auth/login` |
| 当前账号 | `GET/PATCH /api/auth/me`、`GET /api/me` |
| 收藏 | `POST/DELETE /api/products/:productRef/favorite` |
| 评论 | `GET/POST /api/products/:productRef/ratings` |
| 回复 / 有帮助 | `POST /api/ratings/:id/replies`、`POST /api/ratings/:id/helpful` |
| 举报 | `POST /api/reports` |
| 推荐 | `POST /api/recommendations` |
| 后台审核 | `GET/PATCH /api/admin/moderation/reports`、`GET/PATCH /api/admin/moderation/ratings` |
| 操作审计 | `GET /api/admin/audit-logs`，可按对象 / 动作筛选 |

- 前台列表与详情适配：新品类使用独立价格区间和筛选项；卡片展示品类关键参数；详情页按品类切换参数摘要、图片 contain 布局和评分标题，单板专属的硬度 / 进阶指数不再串入新品类；运动相机和公路车价格按 USD 显示。
- 前台详情体验补齐：羽毛球拍、路亚竿的评论表单改用打法水平 / 钓法水平等品类字段；无真实评分时显示“暂无评分 / 等待首批实测”，不再用 0 值制造假数据；非单板详情从 API 同类目数据生成同场景对照卡片。
- 前台对比适配：对比矩阵按品类隐藏单板专属的进阶指数与“最吃技术”结论；对比坞发现跨品类组合时会先提示统一品类，避免生成没有实际意义的横向参数表。
- 前台榜单适配：榜单支持通过品类切换单板、羽毛球拍、路亚竿、运动相机、公路车和山地车，数据从 API 读取并按品类榜单配置计算；投票记录带品类隔离，暂无数据时显示明确的待补充状态。
- 前台问卷与个人中心适配：问卷按品类切换，尚未建立推荐规则的羽毛球拍 / 路亚竿明确显示“问卷待补充”，不复用单板问题；个人中心的档案入口改为通用首页，问卷和投票记录显示中文品类与榜单名称。
- 个人中心记录补齐：收藏、对比、评论、问卷和投票会优先读取本地内容包，遇到 API 新品类 slug 时按每批最多 4 件补读 API 商品详情，避免新增品类在个人中心显示为空。
- 首页多品类入口：精选档案和综合榜支持在单板、羽毛球拍、路亚竿之间切换，读取当前品类 API 数据，并保留本地内容包回退、加载态和空态。
- 详情评论数据：评论区优先使用 API 返回的评分总数、平均分和星级分布；API 没有评论时继续使用本地演示汇总，避免新品类把真实评分显示成 0。
- 详情评分一致性：详情页顶部信息卡复用评论区读取到的 API 评分汇总，用户评分、实测条数和评论列表不再出现上下不一致。
- 登录态同步收口：应用启动和重新获得焦点时自动回填云端账号、收藏、评分和通知；登录成功后先完成 `/api/me` 同步再进入个人中心，失效令牌会清理本地账号态，退出和本地回退登录也会清理云端令牌。
- 前台加载反馈：新增路由级加载占位和统一 shimmer 骨架屏，首页精选 / 榜单、搜索结果、分类榜单、对比页、详情评论摘要及个人中心记录同步均保留真实内容版式，减少加载白屏和布局跳动，并尊重系统的减少动态效果设置。
- 前台异常恢复：API 请求回退本地内容包时会向页面报告回退状态，首页品类、搜索、榜单和对比页显示明确提示并提供“重试”入口；网络异常时不清空已有内容。
- 移动端窄屏回归：按 320px / 375px 视口检查首页、搜索、榜单、对比、个人中心和详情页；修复首页综合榜与社区实测双栏区域被长标题撑宽的问题，主要前台页面不再产生横向溢出。
- 页面异常兜底：升级品牌化 404 档案空态，新增全局错误边界，异常页面提供“重新加载”和“回到首页”操作，避免路由或渲染错误时出现默认白页。
- 单板问卷流程收口：首题进度显示真实百分比；跳题或直接提交时会定位第一个未完成问题，并为选项和题号补充状态语义，避免生成不完整推荐结果。
- 全局搜索回归：搜索 `AURASPEED` 可返回羽毛球拍产品；搜索查询的数据库行补齐封面关联，避免序列化时触发 500；本地回退支持中文点评 / 参数关键词，品类筛选显示中文名称，跨品类结果卡片明确标出所属品类。
- 生产构建回归：`pnpm --filter @youpu/web build` 通过；生产服务下羽毛球拍、路亚竿列表与动态详情路由均返回 200。
