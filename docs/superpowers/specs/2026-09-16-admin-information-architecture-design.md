# 后台管理信息架构与中文化设计

日期：2026-09-16  
状态：已获用户确认，待进入实施计划

## 1. 目标

本次调整只针对后台管理端的信息架构和界面文案：

1. 去掉面向后台使用者的装饰性英文内容，后台操作语言统一为中文。
2. 将数据分析提升为登录后的总览首页核心内容，而不是只能通过侧边栏进入的次要页面。
3. 将产品、品牌、类目和采集导入集中到“资料库”分组，和总览、分析、审核、审计形成清晰边界。

不改变现有 API、数据库、令牌鉴权、产品编辑能力和分析数据契约。

## 2. 导航信息架构

侧边栏改为三个层级：

### 工作台

| 编号 | 页面 | 作用 |
|---|---|---|
| 00 | 总览 | 登录后的默认首页，展示数据分析摘要、内容质量和系统状态 |
| 01 | 数据分析 | 查看完整的趋势、事件、路径和产品互动明细 |

### 资料库

| 编号 | 页面 | 作用 |
|---|---|---|
| 02 | 产品资料 | 产品列表、筛选、编辑、草稿和发布 |
| 03 | 品牌 | 品牌资料维护 |
| 04 | 类目与参数 | 类目层级和 `spec_schema` 维护 |
| 05 | 采集与导入 | 数据采集和导入状态 |

### 内容运营

| 编号 | 页面 | 作用 |
|---|---|---|
| 06 | 内容审核 | 社区举报和评论审核 |
| 07 | 操作审计 | 后台变更记录与前后快照 |

分组标题、页面标题和当前页面指示器全部使用中文。实际数据中的品牌名、型号、`slug`、URL、事件名等业务或技术值保持原样，避免破坏数据辨识度。

## 3. 总览首页布局

总览标题由“资料库总览”调整为“数据总览”，内容顺序如下：

1. **数据分析摘要**：默认展示最近 14 天的独立访客、埋点事件、产品浏览和活跃账号四项指标，并放置访客与事件趋势、事件分布两个紧凑图表。
2. **行为洞察**：展示访问路径和热门产品互动，帮助后台人员先判断用户正在看什么、从哪里进入。
3. **内容质量**：保留缺图片、缺价格、缺来源、缺编辑评分四个可点击补齐入口，点击后进入“产品资料”并自动带上筛选条件。
4. **最近更新与系统状态**：保留最近修改产品和 API、数据库、Redis、搜索服务状态，放在分析和内容质量之后。

总览和“数据分析”使用同一份 `AdminAnalytics` 数据和刷新逻辑：

- 登录后进入总览时同时读取总览数据和默认分析数据。
- 总览中的日期范围与刷新按钮作用于当前分析摘要。
- 进入“数据分析”后继续使用完整明细布局，不重复新增 API。
- 分析请求失败时，总览仍显示产品数量和内容质量；分析区域显示可理解的空态或错误提示，不阻塞后台使用。

## 4. 中文化范围

需要移除或翻译以下英文内容：

- 侧边栏导航备注、顶部栏当前模块标识、品牌锁定区副标题和系统状态文案。
- `SectionHeader`、`PanelHeader` 的装饰性眉题、英文数量后缀和全大写状态词。
- 数据分析、资料库、产品编辑器、品牌、类目、采集、审核和审计页面中的英文装饰标签。
- 仅用于视觉风格的英文 footer、版本说明和操作状态词。

以下内容属于真实数据或必要技术值，不作为中文化对象：品牌英文名、产品型号、产品 `slug`、来源 URL、事件代码、JSON 字段名以及 API 地址。这些值只在需要辨识、复制或排查问题的场景出现，并配套中文字段名。

## 5. 实现边界

- 调整范围集中在 `apps/admin/src/components/admin-app.tsx` 和 `apps/admin/src/app/globals.css`。
- 将导航项增加分组信息，渲染分组标题和分组间距；不改变 `Section` ID，避免影响现有页面状态。
- 从现有分析渲染中抽取可复用的总览摘要组件，完整分析页继续保留趋势、事件、路径、热门产品、最近埋点和系统状态。
- 复用现有 `refreshAnalytics`、`analyticsDays` 和 `AdminAnalytics` 类型；不新增后端接口或数据库字段。
- 保留桌面侧边栏和移动端布局，在窄屏下分组标题仍可辨识，导航按钮和分析卡片不产生横向溢出。

## 6. 错误处理

- 总览分析数据处于读取中时，指标和图表使用现有加载态，不展示错误的零值。
- 分析 API 返回错误时，仅在分析区域显示错误提示，并保留已加载的总览、资料库和质量数据。
- 导航切换、资料库筛选和已有编辑操作保持当前行为；分析刷新失败不改变当前页面。

## 7. 验收标准

1. 登录后台后的默认页面首先看到数据分析摘要，而不是只看到产品数量卡片。
2. 总览页面存在分析指标、趋势或事件分布、访问路径和热门产品等分析内容。
3. 侧边栏明确显示“工作台 / 资料库 / 内容运营”分组，“产品资料、品牌、类目与参数、采集与导入”集中在资料库下。
4. 导航、页眉、卡片眉题、状态和 footer 不再出现仅用于装饰的英文内容。
5. 品牌名、型号、slug、URL、事件代码等真实数据仍可正常显示和编辑。
6. 数据分析独立入口仍可打开完整分析页，产品资料等资料库页面仍可正常切换。
7. 现有管理端类型检查和生产构建通过，桌面与窄屏布局无明显溢出。
