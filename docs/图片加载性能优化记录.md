# 图片加载性能优化记录

更新时间：2026-09-29

## 当前策略

- 首页雪场图使用 1920px 公开摄影素材，保留随机展示、原有构图尺寸与读取进度动画。
- 首页主视觉通过原生 `<img>` 直接请求，不再先 `fetch` 缓冲完整文件再创建 Blob；加载时保留点点 spinner，移除浏览器无法真实提供的字节百分比，首图使用高优先级加载。
- 商品卡片、榜单、对比坞、个人中心和详情图集缩略图使用尺寸受限的缩略 URL；详情页主图保留 1600px 级别清晰度，同时限制已验证 CDN 的超大原图。
- 对比页 56px 装备摘要图请求上限为 192px，规格表图片上限为 480px，避免小图直接请求原尺寸素材。
- 后台产品清单封面缩略图使用浏览器懒加载和异步解码，详情抽屉图片行为不变。
- 已验证的缩放规则仅针对支持并允许的图片来源：Shopify 商品 CDN、Salomon DAM、K2 Amplience、Rossignol、迪卡侬、Specialized 方形主视觉资源、Amer Sports 和 Canyon Cloudinary 的白名单路径。未知来源不改 URL。
- 浏览/搜索结果首张商品卡和榜单首件图使用 `fetchPriority="high"` 优先加载，其余列表项继续懒加载；`SafeImage` 使用异步解码。
- 缩放 URL 仅改变请求尺寸，不代表图片已迁移至自有存储，也不代表已取得外链图片的使用授权。

## 已验证样本

以下为少量 URL 的响应头 `Content-Length` 对比，仅说明样本效果，不代表全目录或所有网络环境的保证：

| 来源 / 样本变换 | 原始字节 | 优化后字节 | 样本降幅 |
|---|---:|---:|---:|
| 将军山首图：3840px → 1920px | 2,541,718 | 817,182 | 67.9% |
| Burton Shopify 图：2880px → 800px | 1,757,039 | 239,564 | 86.4% |
| Shopify DOA 图：无宽度 → 800px | 4,736,194 | 337,374 | 92.9% |
| Salomon DAM 图：无宽度 → 800px | 3,530,364 | 703,840 | 80.1% |
| Canyon Cloudinary 图：`w_1145` → `w_800` | 80,796 | 49,990 | 38.1% |
| K2 Amplience 图：`w=1200` → `w=800` | 245,641 | 105,499 | 57.1% |
| Rossignol 商品图：`sw=800` → `sw=480` | 382,533 | 179,007 | 53.2% |
| 迪卡侬商品图：`f=3000x0` → `f=800x0` | 261,380 | 38,392 | 85.3% |
| Specialized 方形商品图：`w=640&h=640` | 2,491,744 | 299,883 | 88.0% |
| Atomic / Amer Sports：`width=1445,height=10380` → 800×800 bounds | 79,725 | 16,231 | 79.6% |

Shopify 对样本中的 `format=webp` 参数仍返回相同 MIME 和字节数，因此当前不依赖该参数声称有格式压缩收益。Specialized 仅验证并改写 `/i/specialized/*_HERO-SQUARE` 路径的 `w`、`h` 尺寸参数，不追加未经验证的格式转换参数；该样本确认缩小宽高后响应字节下降。Amer Sports 只处理白名单产品路径中 `fit=bounds` 的图片，并将宽高限制在同一上限，CDN 保持等比缩放。Canyon 样本保留原有 `h_645`、`c_fit`、`f_jpg`、`q_auto` 等变换；K2 保留 `qlt`、`fmt`，Salomon、Rossignol 和迪卡侬规则保留其余查询参数。迪卡侬样本确认 `f` 参数缩小宽度可减少响应字节；其他产品 URL 仅在满足精确来源规则时才改写。

## 目录覆盖率快照

截至 2026-09-29，扫描 `data/**/*.yaml` 共 440 个文件、303 个唯一 `images[].url`；按 `preferProductThumbnail` 返回值是否变化统计，236 条会改写，覆盖率约 **77.9%**，其余 67 条保持源 URL。该指标只描述代码处理覆盖，不等于真实流量降幅或全部运行时图片覆盖。

剩余数量较多的来源中，Gray 样本原图仅 63KB（320×530），官网也没有公开缩图变体；Giant 样本当前已是约 25–40KB 级图片；Head 尺寸路径尝试返回 404；Nordica 样本约 1.18MB（1800×6500），常见宽度/格式参数未生效。后续优先找 Nordica、Ogasaka 等尚未确认变体的来源的官方证据；不能确认时保留原图，避免破图或错误裁切。

## 缓存与环境边界

本地图片代理对浏览器返回 `max-age=86400, stale-while-revalidate=604800`；代理的上游 `fetch` 使用 `no-store`，因此目前没有服务器端图片缓存。项目使用静态导出时，生产页面通常直接请求来源 CDN，代理代码不能证明生产 CDN 的实际缓存策略。生产优化需要以线上 Network 面板和 CDN 响应头复核，不能从本地结果推断。

## 后续验证顺序

1. 对已登记的图片来源继续小批验证尺寸 URL：必须检查状态码、MIME、响应字节数，并保证裁切/长宽比没有变化。
2. 用浏览器 Network 面板抽查首屏与滚动后的实际图片请求，分别记录冷缓存和热缓存；不要把源码规则覆盖率当成实际下载量。
3. 若需把外链素材迁至火山引擎 TOS，应先生成审核清单并逐项确认授权；现有迁移工具不会默认上传或改写商品资料。上传及数据库同步需按 README 的迁移流程单独执行。
