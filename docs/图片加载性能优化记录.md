# 图片加载性能优化记录

更新时间：2026-09-29

## 当前策略

- 首页雪场图使用 1920px 公开摄影素材，保留随机展示、原有构图尺寸与读取进度动画。
- 首页主视觉通过原生 `<img>` 直接请求，不再先 `fetch` 缓冲完整文件再创建 Blob；加载时保留点点 spinner，移除浏览器无法真实提供的字节百分比，首图使用高优先级加载。
- 首页随机主视觉保留客户端抽图和原有 spinner，同时使用异步图片解码，避免图像解码同步阻塞主线程绘制。
- 商品卡片、榜单、对比坞、个人中心和详情图集缩略图使用尺寸受限的缩略 URL；详情页主图保留 1600px 级别清晰度，同时限制已验证 CDN 的超大原图。
- 对比页 56px 装备摘要图请求上限为 192px，规格表图片上限为 480px，避免小图直接请求原尺寸素材。
- 后台产品清单封面缩略图使用浏览器懒加载和异步解码，详情抽屉图片行为不变。
- 已验证的缩放规则仅针对支持并允许的图片来源：Shopify 商品 CDN、Salomon DAM、K2 Amplience、Rossignol、迪卡侬、Specialized 方形主视觉资源、DJI Action 4/5 Pro 官方小图、Nordica 官方 WebP 缩图、GoPro 官方 WebP 优化端点、Amer Sports 和 Canyon Cloudinary 的白名单路径。未知来源不改 URL。
- 浏览/搜索结果首张商品卡和榜单首件图使用 `fetchPriority="high"` 优先加载，其余列表项继续懒加载；`SafeImage` 使用异步解码。
- 全局常驻对比坞中的商品图仅显示为 36×36px；Shopify 图片请求限制到 96px，覆盖约 2 倍设备像素比，其他来源继续沿用各自已验证规则。
- 评论列表中的自有 TOS 图片以 160/240px WebP `srcSet` 适配 80px 展示尺寸和 DPR；TOS 公开样例中 160px 为 2,090 字节、240px 为 3,350 字节（减少约 37.6%，非用户图片样本）。点击仍打开原图，若缩略变换不可用则自动回退原图；尚无本地真实评论图片可用于测量实际投稿图的字节收益。
- 修复 `SafeImage` 对无 MIME 类型的普通 `srcSet` 未挂载到 `<img>` 的问题；响应式候选现按 `sizes` 生效，Typed WebP 候选仍只挂到 `<picture><source>`，回退原图时会清除变体候选。
- 个人中心的对比历史与问卷结果图片、对比页候选装备图片展示为 36–40px；Shopify 图源请求收窄到 96px，非 Shopify 图源仍使用原 480px 策略及其供应商专用变体。
- 商品详情页当前选中的主图使用 `loading="eager"` 与 `fetchPriority="high"`；图集缩略图仍保持懒加载，减少首屏主图等待调度的可能。
- 后台产品清单 52px 封面缩略图仅对 Shopify 图源限制为 96px，保留 URL 版本参数；其他图源与产品详情图仍使用原始 URL。
- 缩放 URL 仅改变请求尺寸，不代表图片已迁移至自有存储，也不代表已取得外链图片的使用授权。

## 目录覆盖率快照

首页随机雪景图为 4 张 Wikimedia Commons 摄影素材增加响应式候选：1280px 同构图作为常见屏幕候选，保留 1920px 供高密度屏幕选择。实测 1280px 版本均为 200 JPEG，较 1920px 原候选分别少传约 52.8%、53.2%、52.5%、56.9%；1024px 与 640px Commons URL 返回 HTML 错误页，不使用。源图与 1280px 版本等比，抽样 RGB 平均差 1.8–5.5/255。该改动仅调整浏览器选择的资源尺寸，不变更随机图池、布局高度、加载动画或过渡效果。

VICTOR AURASPEED 100X SE 仅将卡片图换为官网同 SKU `640x` JPEG 变体；原图文件名带 `2048x`，追加 `width=640` 实测没有缩小效果，因此使用已确认的精确静态变体，详情保留高分辨率源图。

Union Atlas、Atlas Pro、Force、Force Classic、Legacy、Trilogy、Ultra 七款固定器的源文件名带 `_2000x`；CDN 忽略 `width=640` 查询参数，改用同文件版本的官方 `_640x` 变体。实测每张从 2000×2000 降至 640×640，响应体减少约 77.6%–82.3%；详情保留原图。

KORUA Café Racer 使用官网商品页引用的同一 Accentuate 文件，仅把原图域名切到官方 CDN 并追加 `transform=resize=640`（窄卡片使用 416）；640px WebP 样本减少约 77.2%，详情保留原始图片。Accentuate 官方文档说明 `transform=resize=<width>` 可在保持比例的情况下缩图。[Accentuate 图片缩放文档](https://help.accentuate.io/liquid-guides/resize-and-crop-images/)

截至 2026-09-29，扫描 `data/**/*.yaml` 共 440 个文件、303 个唯一 `images[].url`；按 `preferProductThumbnail` 返回值是否变化统计，278 条会改写，覆盖率约 **91.7%**，其余 25 条保持源 URL。新增 5 条 Nordica、3 条 GoPro、5 条 HEAD、3 条 Follows、5 条 Giant、4 条 Canyon Cloudinary、7 条 Union 固定器、1 条 KORUA Café Racer、1 条 Flow Fuse、1 条 SmartMarine、1 条 Point、1 条 VICTOR AURASPEED、1 条 Decathlon SNB 100、DJI Action 6 和 Canyon Neuron CF 8 图片，仅在官方同图缩图/优化路径核验后改写。该指标只描述代码处理覆盖，不等于真实流量降幅或全部运行时图片覆盖。

Nordica 目前只映射 5 个已验证 SKU 到官方同图 WebP 档位（56/112/168/640/1280px）；其余 Nordica 图片保持原样。GoPro 只映射 HERO11、HERO12、HERO13 三张已验证图片到官方 WebP 优化端点：卡片请求 375px，详情请求 1280px；三张卡片原图合计 182,866 字节，375px WebP 合计 20,482 字节，样本合计约减少 88.8%；其他 GoPro 图片保持原样。Follows 三款（R2、Riders Spec DR、RX）与 Point 一款目前只映射已核验的精确 URL 到官方小图，详情仍使用原图；没有把结论外推至同品牌其他图片。CAPiTA 目前只将 6 张实测图片（SB Resort Twin、Aeronaut、Super D.O.A.、D.O.A.、Outerspace Living、Sidewinder）卡片尺寸从 800px 降至 416px；在浏览器 Accept 格式协商下，样本合计从 150,110 字节降至 63,986 字节（约减少 57.4%），详情主图仍请求 1600px。HEAD 目前有 5 张雪板图使用官方缩略变体（683×911卡片、224×298紧凑布局），详情仍保留 1820×2428 源图；e-SLR 的 683×911 变体从 65,908 字节降至 11,462 字节（约 82.6%）。Atomic Bent Chetler 120 与 Insta360 Ace Pro 2 的精确商品图使用响应式 `srcSet`；前者仅切换同一图床的 `!small`、`!middle` 尺寸档，后者使用 OSS 同路径 q90 WebP：376×480 原尺寸变体为 17,438 字节，窄布局 188×240 为 7,026 字节，源 YAML/详情仍保留 PNG 原图。卡片 `sizes` 按网格内容区与断点计算，浏览器按实际展示宽度、DPR 选择；这两条规则不外推至品牌其他图片。DJI 目前仅将 Action 4、Action 5 Pro 和 Action 6 三张核验过的官方图片切换到 `@retina_small` 档；Action 6 的两档都实际返回 PNG，缩小本身约减少 73.5%。Giant 目前只将 Propel Advanced Pro、XTC Advanced、Defy Advanced 2、TCR Advanced Pro 0 AXS、Trance X Advanced 0 五款已核验图片缩为官方 300×200 档，保留 `c_pad` 不裁切商品主体；Defy/TCR 比例由 4:3 调为 3:2，卡片 `object-contain` 呈现。Canyon Neuron CF 8 精确映射到官方同一 P5 图片的 543px 缩略图；在 `Accept` 内容协商下，响应 WebP 样本由 160,402 字节降至 27,982 字节（约减少 82.6%），详情仍保留原图。另有 Aeroad CF SLX 7 Di2、Endurace CF 7、Endurace CF 7 Di2、Spectral CF 7 四款精确 Cloudinary 资产改用同商品 543×305 图，样本减少 60.4%–66.2%，保留 `c_fit`、背景色（如有）、JPEG 与质量参数；详情仍请求原始大图。Neuron 416px PNG 候选实测反而更大，因此不使用。Flow Fuse 目前仅将这一款固定器卡片切换到同构图官方 416px 图片；详情图仍保留 800px。SmartMarine 目前仅将 Shimano LIMITLESS 这一款钓竿的 1200px `xlarge` 图切换为同路径 600px `large` 图，其他商品保持原样。其他剩余来源中，Gray 样本原图仅 63KB（320×530），官网也没有公开缩图变体；Ogasaka 原图为 350×1000、约 260KB，官方图床对常见缩放/格式参数不响应。其他 Insta360 宣传图的响应式图构图与目录封面不一致或体积更大；Ace Pro 2 仅对这一张精确图源使用同路径 OSS 缩放/WebP 变体。不能确认时保留原图，避免破图、错图或错误裁切。

## 本地运行时抽查

2026-09-29 在本地页面核验：`/browse/snowboard` 首张商品图为 eager/high、后续图片为 lazy/auto；`/rankings` 榜首图为 eager/high、其他榜单图为 lazy/auto；`/browse/action-cam` 的 DJI Action 4 和 Action 5 Pro 都通过图片代理加载为 640×640 的官方小图。Atomic Redster Q9 详情主图通过代理加载为 282×1600；代理分别按 AVIF 与 JPEG 的 `Accept` 返回 200，并带 `Vary: Accept`。这些是本地抽样，不替代真实用户网络下的生产监控。

2026-09-30 在本地浏览器发现首页原创山脊 PNG 主图原始宽度为 2688px，首屏实测传输 5,592,923 字节。保留远端原图作为 `<img>` 回退，并新增 768px、1440px 两档本地 WebP 候选（分别 34,850、140,702 字节）；浏览器在约 650px 展示宽度下实际选择 768px 候选，实测传输 35,150 字节，较 PNG 原请求减少约 99.4%。尺寸通过 `<picture>` 和 `sizes` 响应式选择，未更改随机图池、首屏布局或过渡效果。原始 CDN PNG 未覆盖或删除；1440px 档供高密度桌面使用。此数据来自本地浏览器单次冷缓存抽查，不代表线上传输或所有视口结果。

同日为首页 4 张有 Commons 授权记录的雪景摄影图增加本地 768px 与 1280px WebP 候选；页面保留原 Wikimedia JPEG `srcSet`、来源页和署名作为非 WebP/资源失败时回退。WebP 文件分别为 20,546–111,242 字节（768px）、82,368–353,644 字节（1280px）。本地浏览器实际加载将军山 768px WebP 为 111,542 字节；与此前测得的同图 1280px JPEG 385,436 字节相比约减少 71.1%。其余照片变体依据已核验的官方 1280px 图片生成，未修改原图或照片来源；不同图片与 DPR 的最终节省量会不同。

同日检查商品详情时，Insta360 Ace Pro 2 图集仍以原始 PNG 作为主图和懒加载缩略图，页面 376×480 PNG 响应体为 48,645 字节。将该精确白名单图片的既有官方 OSS 变体接入详情主图及缩略图：主图同尺寸 q90 WebP 为 17,438 字节（约减少 64.2%），188×240 缩略图为 7,026 字节（约减少 85.6%）。`<picture>` 的 WebP source 只用于该精确资源；原始 PNG 仍作为不支持 WebP 时的回退。开发环境的本地图片代理 URL 也保留在变体候选中。响应体和尺寸在本地浏览器通过图片代理实测，线上效果尚未核验。

商品详情图集缩略图显示尺寸为 64–80px，Shopify 源图此前仍按 640px 上限请求。将支持 Shopify 宽度参数的图集缩略图上限收窄至 240px（80px × 3 DPR），不影响主图；Burton Cartel X Re:Flex 2027 精确官方图通过本地代理实测，640px WebP 为 81,224 字节，240px WebP 为 21,462 字节，减少约 73.6%。非 Shopify 且没有受支持缩图规则的源保持原样；其他已验证品牌专用缩图分支仍按各自规则处理。

同日发现商品目录卡片中的 Shopify 图片仍使用 640px 变体，而雪板卡片实际图片盒约 225px 宽。将目录和搜索中的商品卡片缩略图处理上限设为 480px，不影响首页/榜单较大卡片、详情主图或图集缩略图。本地浏览器通过图片代理对同一张 Shopify 单板商品图实测：640×960 WebP 为 19,882 字节，480×720 WebP 为 13,526 字节，减少约 32.0%；迪卡侬 SNB 100 同时由 800×800、18,820 字节降至 480×480、7,051 字节，减少约 62.6%。480px 覆盖约 225px 卡片在 2× DPR 下的像素需求。已渲染来源在滚动卡片外仍保留 `loading="lazy"`，首张商品卡片继续按原 eager/high 策略加载。数据为本地样例实测，其他视口、图片来源与生产 CDN 需另行核验。

榜单完整名次的 `GearRow` 图片盒只有 56×56px，但 Salomon 商品图仍按 800px 请求。仅对榜单完整名次将缩略图目标设为 168px（56px × 3 DPR），不改变其他 `GearRow` 调用；页面原有懒加载保持不变。Salomon Dialogue Dual BOA Team 图片通过本地代理实测，800px 请求响应为 992×992 WebP、390,792 字节；168px 请求响应为 208×208 WebP、20,894 字节，减少约 94.7%。CDN 返回尺寸高于请求宽度，因此保留实际响应尺寸记录；线上 CDN 表现尚未核验。

## 缓存与环境边界

本地图片代理对浏览器返回 `max-age=86400, stale-while-revalidate=604800`；代理的上游 `fetch` 使用 `no-store`，因此目前没有服务器端图片缓存。代理按浏览器声明的栅格格式协商上游响应，仅在浏览器明确接受时请求 AVIF；无 `Accept` 或 q=0 时使用兼容格式，并拒绝上游不遵守格式协商的响应。代理在响应中设置 `Vary: Accept`；允许 AVIF、WebP、JPEG、PNG、GIF 栅格图片，同时继续拒绝 SVG 等非栅格响应。项目使用静态导出时，生产页面通常直接请求来源 CDN，代理代码不能证明生产 CDN 的实际缓存策略。生产优化需要以线上 Network 面板和 CDN 响应头复核，不能从本地结果推断。

## 后续验证顺序

1. 对已登记的图片来源继续小批验证尺寸 URL：必须检查状态码、MIME、响应字节数，并保证裁切/长宽比没有变化。
2. 用浏览器 Network 面板抽查首屏与滚动后的实际图片请求，分别记录冷缓存和热缓存；不要把源码规则覆盖率当成实际下载量。
3. 若需把外链素材迁至火山引擎 TOS，应先生成审核清单并逐项确认授权；现有迁移工具不会默认上传或改写商品资料。上传及数据库同步需按 README 的迁移流程单独执行。
