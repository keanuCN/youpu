# 单板数据完善（2026-10-12）

本轮复核仓库 77 款单板，优先补齐缺少逐尺码表的 2027 年款。27 款已回写，共新增 208 条逐尺码参数；尺码表覆盖由 35/77 提高到 62/77。另纠正 Salomon Huck Knife 2027 的 156 代表码腰宽和侧切。

## 已确认的修正

- CAPiTA Aeronaut、Indoor Survival、Mega Death、Mega Merc、SB Resort Twin、Sidewinder、The Black Snowboard of Death、The Navigator：删除只保留首个半径的单值 sidecut，改为保留官方完整多段 sidecutRadii。Death Grip 的负数/多段原文不截断、不折算为单一半径。
- CAPiTA Ultrafear 2027：153 标准码的 sidecut 由 8.26 m 改为官方 7.8 m。
- Jones Freecarver 6000s：代表码固定为官方 154 标准宽，腰宽 248→263 mm、板重 2700→3000 g；旧值来自 154N 窄版，全表将 N 版分列。
- Jones Twin Sister：149 码补入板重 2400 g、有效刃长 1150 mm、侧切 7.2 m；站位后移 20→0 mm。
- Nitro Alternator：157 码 setback 保留官网 -15 mm，并保留三段侧切 10.8/6.8/10.8 m。负号遵循厂商原表。
- RIDE Deep Fake 与 WARPIG：记录 entry/focus/exit 各段，官网的横杠保留为未提供；不填补缺失段。Deep Fake setback -19 mm，WARPIG 0 mm。WARPIG 的代表 154 明确对应 LARGE (154)，不因字母尺码而跳过或换码。
- Salomon Huck Knife：官方货号 L49292200 的 156 码腰宽为 255 mm；旧 248 mm 是 149 码的数值；侧切同样由错用 149 码的 7.1 m 修正为 156 码的 7.5 m。现有逐尺码表与官网交叉一致。

## 录入边界

- 新表包含板腰、板头尾宽、有效刃长或独立 Running Length、侧切、站距、后移；Jones 额外包含接触长度、前后脚处宽度、板头尾长度和 taper。板重、体重建议与靴码仅在官方明确给出时录入。
- 几何尺寸统一 mm，板重统一 g；官方 cm/kg 及原文保留在 JSON 证据中。建议骑手体重与整板重量分开。
- Jones 用 JSON-LD 的 J.27 SKU 核对季节；CAPiTA Sidewinder/Matriarch 的标题不含年份，使用其官方 canonical 与 Product.url 的 2027 路径作为季节依据。
- 不把 Running Length 当作 Effective Edge；CAPiTA 未明确单位的 Taper 仅保留在证据中，不猜测单位。建议靴码中 M 等缩写保留原文，不自行转换为 EU。
- 本轮不改变价格、评分、图片、产品文案。地区价格、同季雪测和图片授权仍沿用既有待核状态。
