# SP BASE 2025/26 固定器资料纠错

核验日期：2026-10-28。

此前档案将 BASE 写成普通绑带、不支持快速入脚，是对官方说明的误读。SP 日本官网 [BASE 商品页](https://sp-bindings.jp/products/base)将该款描述为柔和脚感、面向入门者，并介绍便捷入脚设计；[品牌技术页](https://sp-bindings.jp/pages/technology)在是否能像传统绑带固定器一样使用的问题下，将 BASE 与 KIDDO 列为例外。因此修正为快速入脚，并提示购买前核对具体操作方式，不声称 BASE 支持双入口。商品页通用技术介绍与具体型号说明应区分阅读。

[官方尺码表](https://sp-bindings.jp/pages/sp-bindings-size-chart)将 BASE 列入 FT4 底盘：S 22–25、M 25–27.5、L 27.5–29.5、XL 29.5–32 cm。尺码仅供参考，须以雪鞋实物试装。
